# BJTU MIS Android v1.4.3 更新说明

版本名称：`v1.4.3`；Android 版本号：`10`。上一正式版本为 `v1.4.2`（版本号 `9`）。

本次更新为智能助手接入原生校园工具、待办与提醒，增加用户可选的插件自启，并完善空教室筛选和插件更新交互。

## 智能助手与原生校园页面

- 普通聊天可使用原生课表、考试、作业和日程聚合查询；默认读取本地缓存，主动刷新仍须用户确认。缺失、过期、部分失败或日期未核实的数据会明确标记。
- 助手可经原生确认创建、编辑、完成和删除 App 待办，设置或取消一次性通知提醒，并打开课表、考试、学年日历、作业和课程资源等白名单原生页面。
- 待办与提醒使用原生日历的同一份数据；编辑、完成或删除待办会撤销旧提醒。提醒受系统后台调度影响，不保证精确到时。
- 工具执行保留前台、参数、工作区、确认及请求去重边界；校园数据交给模型前提示用户。邮件发送仍需确认，助手不自动提交课程作业。

## 插件自启与更新体验

- 新增 `android.app.autoStart@1` 可选能力，默认关闭。用户明确开启后，打开主应用且主 Activity 可见时，宿主可加载该插件本地入口。
- 自启不包含开机启动或永久保活；后台仍提供持续通知和全部停止入口，全局最多同时运行 4 个插件。撤销、禁用、复审、更新或回滚会停止相应运行实例。
- 完善插件详情、安装和更新入口、增量授权展示，以及 README 与运行要求的独立滚动；隔离过期请求，减少快速切换时内容错配。
- SDK、契约、Schema、校验器和开发者文档同步新增能力。Manifest v3 / contract_v1、稳定本地 main-frame 桥及分域联网等安全规则保持有效；旧 WebView 缺少安全传输功能时拒绝启动插件。

## 空教室筛选

- 按星期或日期、开始与结束节次筛选，直接显示整个所选时段都空闲的教室及座位信息。
- 连续节次、开始节次调整和跨周数据刷新会保持有效的筛选范围；缺少时段信息时不显示未经验证的空闲结果。

## 升级与验证

- 同步更新插件平台自启契约，并升级 Fastify 及受影响的 URI/路由依赖，修复上游已披露的问题。
- 最低 Android 版本仍为 Android 8.0（API 26），正式 APK 保持原应用 ID 和正式签名，发布前核验覆盖升级所需的证书一致性。
- 本次没有新增 Room 数据库迁移。
- 设备测试通过 Compose 语义与实际滚动验证日历导航；插件自启测试分别验证安全 WebView 的启动/撤销，以及不支持安全传输时的拒绝启动。
- 发布结果、签名与 APK 摘要、API 26/35 CI 和环境限制以对应发布验证记录为准；未执行的场景不视为已验证。
