# BJTU MIS Android v1.4.4 更新说明

版本名称：`v1.4.4`；Android 版本号：`11`。上一正式版本为 `v1.4.3`（版本号 `10`）。

本次修复学校统一认证升级后，未登录却提示“当前会话似乎已登录”、验证码加载失效及登录无法继续的问题。

- 兼容新的 SSO 登录表单和认证地址，按校方协议使用 SM2 公钥加密密码；不需要验证码时直接登录。
- 认证服务要求图片验证码时再显示输入框；刷新失败立即清除旧图和旧挑战，避免继续提交失效验证码。
- MIS、教学支撑平台返回认证页时正确判定会话过期；只有最终会话验证成功后才报告登录成功并保存新凭据。
- 保留旧 CAS 数学验证码兼容和原有安全存储，不新增权限、数据库迁移或依赖。

Debug、Release 各 532 项单元测试通过；Android 12 / API 31 真机账号登录成功。网证和企业微信的手机原生跳转授权尚未接入，本次不包含该功能。
